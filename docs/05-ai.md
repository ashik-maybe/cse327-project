# AI Design

4 features: intake (Bangla→English + triage), triage (category/urgency/nextContact), anonymize (safety), follow-up (optional).
Provider values: gemini, fallback, regex, regex+gemini, sample.
No AI = core CRUD still works. No blocking.
Intake: text (banglaText), audio (multipart), sample (sampleId). Response: englishSummary + triage fields + originalText.
Fallback: keyword rules for category/urgency; category mapping for next contact (shelter→Shelter Focal Point, health→Health Post, food→Food Distribution Point, ...).
Anonymize: regex redaction first; optional gemini cleanup. Returns anonymizedText + redactionCount + provider.
Demo fixtures: include fixtures for stable demo when GEMINI_API_KEY absent.

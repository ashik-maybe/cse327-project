# Demo Flow

1. Login as volunteer (volunteer@campbridge.local / demo1234).
2. Volunteer dashboard shows quick actions.
3. Create case: use Bangla sample fixture. AI returns English summary + triage. Confirm/save.
4. Logout/login team lead (lead@campbridge.local / demo1234).
5. Lead dashboard shows team queue.
6. Assign case to volunteer; update status to in_progress.
7. Create safety report with anonymization preview; submit.
8. Lead reviews anonymized reports; updates status to acknowledged.
9. Open map; filter health_post; show details; open external directions.
10. Show offline pending case; sync when online.
